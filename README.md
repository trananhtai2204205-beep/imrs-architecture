
# IMRS - Software Architecture

## Giới thiệu

Repository lưu trữ các bài thực hành kiến trúc
phần mềm có AI hỗ trợ cho hệ thống Intelligent
Medical Record System (IMRS).

## Lab 4 - AI-Assisted Analysis & Design

Chủ đề: Thiết kế phân hệ tra cứu tri thức RAG
và ghi quyết định kiến trúc bằng ADR.

### Nội dung thực hiện

- Phân tích Architectural Drivers.
- So sánh Vector Database, Embedding Service,
  cơ chế phân quyền truy xuất.
- Kiểm chứng các khẳng định kỹ thuật của AI.
- Thiết kế Flowchart và Sequence Diagram.
- Ghi hai Architecture Decision Records.
- Ghi nhật ký AI và các điều chỉnh của sinh viên.

## Cấu trúc

- `context-pack.md`: Bối cảnh hệ thống IMRS.
- `AI_LOG.md`: Nhật ký AI.
- `lab4/LAB4_RAG_DESIGN.md`: Báo cáo Lab 4.
- `lab4/images/`: Hình sơ đồ.
- `adr/`: Hồ sơ quyết định kiến trúc.
